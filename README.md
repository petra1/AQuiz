# Documentation: Layout Adjustment
The layout of the quiz screen has been modified. The progress indicator, which displays the current question number (e.g. "Question 1 of 6“), has been moved from its original position at the top of the screen. It is now situated lower down, placed specifically between the question card and the selection of answers.
